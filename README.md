# ИТС Баланс

Одностраничная панель для сверки покупок и назначений подписок АТОЛ Connect ИТС
между организациями «ВИТМА-С» и «ВИТМА-КЛИМАТ».

## Как пользоваться

1. Нажмите «Обновить данные».
2. Дождитесь завершения фоновой синхронизации на сервере.
3. Назначьте каждому найденному инженеру организацию.
4. Выберите период и сверьте заказанное количество, расход и остаток.

Покупки загружаются из ЛКП отдельно для «ВИТМА-С» и «ВИТМА-КЛИМАТ» и
относятся к периоду по дате отгрузки. Назначения загружаются из АТОЛ Connect
и учитываются только для подписки «АТОЛ Connect. ИТС на 1 год». Авторизация
выполняется фоновым браузером на сервере, без открытия окон.

Сопоставление инженеров и последняя успешная синхронизация сохраняются в
общем серверном файле `server-data/runtime-state.json`. Запись атомарная:
последнее успешное состояние сохраняется при перезапуске и доступно всем
компьютерам локальной сети. Открытые страницы проверяют обновления каждые
30 секунд и при возвращении на вкладку.

Расчёт остатков начинается с 31.07.2026 11:07 по красноярскому времени.
Исходные внутренние остатки: ВИТМА-С — 1711, ВИТМА-КЛИМАТ — −5, общий
фактический остаток AC — 1706. Все последующие закупки увеличивают остаток, а
назначения годового ИТС уменьшают его.

## Локальный запуск

Требуется Node.js 22.13 или новее.

```bash
npm install
npm run dev
```

Команда одновременно запускает панель и локальный помощник АТОЛ. Помощник
слушает только `127.0.0.1:4317` и принимает запросы только от локального сайта.

Перед переносом на сервер скопируйте `.env.example` в `.env.local` и заполните:

```dotenv
ATOL_LOGIN=ваш_логин
ATOL_PASSWORD=ваш_пароль
ATOL_HEADLESS=true
```

`.env.local`, профиль браузера и общий файл данных исключены из Git. Учетные
данные вводятся только непосредственно на сервере и не должны передаваться в
чат или храниться в исходном коде.

Проверка сборки:

```bash
npm run lint
npm run build
```
